IP 管理

              第一层：IP
              IP → 平台 → 账号，数据与图表都按这个层级隔离
            

            

              IP 就是「这一份数据属于谁」——可以是公司名（例：XX 公司官方号），也可以是个人 IP（例：雅雅）。
              先在下面建立 IP，再到「数据看板 → 齿轮」里给每个 IP 添加它在各平台的账号。
            

            

              

                
                

              

              

                
                

                  
                  
                

                

                  小提示：一个 IP 下可以挂多个平台账号（如「雅雅」→ 小红书、抖音）。
                  在数据看板顶部先选 IP、再点平台，下方表格与图表就只显示这一份数据；首页概览也能单独切换查看。
